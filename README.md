# Atomic agent examples

Examples of AI agents that use Atomic's APIs and Transact SDK. Each example has its own setup instructions, dependencies, and environment configuration.

## Examples

| Example | What it demonstrates | Stack |
| --- | --- | --- |
| [Subscriptions](./subscriptions/README.md) | Find merchants, connect accounts, and guide users through subscription cancellation. | Node.js, LangChain, Express, SQLite, and Expo / React Native |

Start with the example's README and run its commands from that example's directory.

## Adding an example

Give each example a directory named for the task it helps a user complete. Include a README with prerequisites and setup instructions, keep its dependencies and configuration in that directory, and add it to the table above.
